# Calculadora Grid
Una aplicación de calculadora de escritorio desarrollada con una interfaz basada en cuadrículas (Grid). Permite realizar operaciones matemáticas básicas de forma intuitiva.

## Características
- Interfaz gráfica limpia y adaptativa utilizando layouts de tipo Grid.
- Operaciones aritméticas estándar: suma, resta, multiplicación y división.
- Historial de operaciones recientes.
- Soporte para tema claro y oscuro.

## Tecnologías utilizadas
-C# (.Net MAUI -- .NET OPEN MAUI)

## Requisitos
Asegúrate de tener instalado Python en tu sistema antes de ejecutar el proyecto.
